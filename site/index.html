Factory as code

Change the line,
not the engine.

A TOML blueprint defines stages, human gates, limits, sandbox policy, targets, and PR labels. The same file becomes an Airflow DAG and a CLI command.

  • ✓ Dynamic task mapping across issues and targets
  • ✓ Typed plans, reviews, and run reports
  • ✓ Retry-safe, idempotent delivery
blueprints/default.toml 
[blueprint]
name = "factory"

[stages]
order = [
  "intent", "spec", "plan",
  "build_and_test", "review", "deliver",
]

[[gates]]
after = "plan"
timeout_h = 24

[limits]
max_build_iterations = 3
budget_usd = 25.0

[sandbox]
kind = "islo"
No keys. No network. About ten seconds.
